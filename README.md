Website ini merupakan portofolio pribadi saya yang saya kembangkan sebagai proyek untuk tugas 1 PBP Semester Gasal 2026/2027. Portofolio terbagi menjadi 4 bagian. Pertama adalah hook website yang mengandung nama, bio, npm, jurusan, link email, linkedin, dan email. Bagian kedua masuk kedalam riwayat edukasi dari era smp, sma, dan kuliah S1. Bagian ketiga mengandung skills, terbagi menjadi hard dan soft skills. Bagian terakhir merujuk pada proyek, organisasi, dan kepanitian dahulu yang pernah diikuti.

Pembuatan website ini tidak menggunakan AI. Saya membangun website ini dari template awal yang tim asdos PBP berikan untuk bagian bio website dan saya gunakan template itu serta w3school dan stack overflow untuk menyelesaikan kendala yang dialami serta otak-atik dan belajar bagaimana html dan css bekerja.

Pertanyaan Refleksi:
1. Dalam pengalaman saya, semantic sendiri tidak perlu digunakan karena div sudah mewakili untuk styling css dan indentation serta nama class sudah bisa menceritakan bagian itu bekerja buat apa. Namun, semantic sangat berguna dan akhirnya saya gunakan karena nama-nama semantic di html (article, header, footer, section, sidebar) dapat menceritakan apa yang div, indentation, dan nama class menceritakan hanya dengan 1 kata saja

2. Tantangan besar yang saya alami adalah lokasi-lokasi benda dalam html setelah di style dalam css. Terkadang, hasil kodingan kita jauh berbeda dari tampilan yang diinginkan di web, dan jauh beda lagi dari tampilan mobile. Sejauh ini, saya menggunakan rem agar spacing di laptop maupun mobile consisten serta prioritaskan ketengahan teks dan objek agar mata pengguna lebih ketengah dibanding harus bergeser kekiri mulu.

3. Secara tampilan, saya tidak melihat masalah dalam cara menampilkan data yang saya berikan ke website, masalah yang ada yaitu jenis data yang dapat saya berikan. Karena website ini sifatnya static, data yang saya berikan adalah data yang saya punya dan/atau pikirkan saat saya koding, hasilnya website mudah menjadi outdated dan ketinggalan zaman.
